# مؤتمر ميلادا عجيبًا — موقع المؤتمر

نسخة GitHub-ready من موقع مؤتمر الشباب، مبنية على مشروع الموقع السابق مع تحديث الهوية والمحتوى للمؤتمر الجديد.

## بيانات المؤتمر
- **الاسم:** ميلادا عجيبًا
- **التاريخ:** 24–26 أغسطس 2026
- **المكان:** بيت الماء الحي — بنها
- **الهوية:** بيج فاتح + ذهبي + أسود مع لمسة نبيتي

## التشغيل على GitHub Pages
1. ارفع **محتويات هذا المجلد** إلى Repository جديد (وليس ملف ZIP نفسه).
2. من **Settings → Pages** اختر **Deploy from a branch**.
3. اختر `main` ثم `/ (root)` ثم Save.
4. انتظر نشر الموقع وافتح الرابط الذي يعطيه GitHub Pages.

> الموقع واجهة Front-end ثابتة، لذلك بعض وظائف الإدارة/الخدمات التي تعتمد على Backend أو Google Apps Script تحتاج إعداد الخدمة الخاصة بها ولن تعمل بمجرد GitHub Pages وحده.

## أقسام المؤتمر الجديدة
- عجلة الأقسام في منتصف الشاشة.
- المحاضرات مع مساحة مخصصة لأسئلة ودرجات الفرق.
- لحن المؤتمر: الصور + الصوت + كلمات اللحن.
- برنامج الأيام 24 و25 و26 أغسطس.
